📚 Online Learning System (Java + MySQL)
🚀 Project Overview
The Online Learning System is a Java-based application that manages students, courses, and enrollments using a MySQL database.
It includes both Console-based and GUI-based implementations for better usability and learning.

✨ Features
👨‍🎓 Student Management
View all students
Add new student
Update student details
Delete student
📖 Course Management
View all courses
Add new course
Update course details
Delete course
📝 Enrollment Management
View enrollments
Add enrollment
Update enrollment
Delete enrollment
💻 GUI Features
Tab-based interface (Students, Courses, Enrollments)
Search functionality 🔍
Table sorting
Dark mode 🌙
Styled buttons and modern UI

🛠️ Technologies Used
Java (Core + Swing)
MySQL Database
JDBC (Java Database Connectivity)

⚙️ Setup Instructions
1. Install Requirements
Java JDK (8 or above)
MySQL Server
2. Create Database
CREATE DATABASE OnlineLearning;
USE OnlineLearning;

3. Update Database Credentials
In both Java files, update:
static final String USER = "root";
static final String PASS = "dbms";

4. Run the Project
▶ Console Application
Run:
Onlinelearningsystem.java
▶ GUI Application
Run:
OnlineLearningGUI.java
